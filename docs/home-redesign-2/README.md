# ホーム画面のデザイン改善（第2段階）

比較ページ： [compare.html](compare.html)（変更前・標準・試作を、状態×端末ごとに3列で表示）
撮り直し：
```
node tools/home-shots.mjs docs/home-redesign-2/after-calm calm
node tools/home-shots.mjs docs/home-redesign-2/after-bold bold
node tests/home-e2e.mjs        # ホームの導線・はみ出し・見た目の切り替えの確認
```

## 見た目は2種類（設定で切り替え）
| | 標準（落ち着いた配色） | 試作（大胆な配色） |
|---|---|---|
| 考え方 | 白いカードは「次にやること」の1枚だけ。ほかは太い罫線と細い区切り線で分ける | 青い色面＋黄色のボタン＋珊瑚色の記録欄。角を立て、黒い太線で囲む（参考画像1の方向） |
| 強調色 | 藍色を「押す場所」と「いまここ」だけに使う | 黄色を「押す場所」と「いまここ」に使う |
| 切り替え | 設定 →「ホーム画面の見た目」 | 同左 |

切り替えは表示だけの好みで、学習記録（`ea-study-v1`）とは別の `ea-home-style` に、その端末のブラウザへ保存します。
保存できない環境（プライベートブラウズなど）では標準のまま表示します。HTML は同じで、CSS だけが違います。

## Impeccable（デザイン検出ツール）
公式の npm パッケージ `impeccable@4.8.2` を作業用フォルダに入れ（インストール時のスクリプトは無効化）、
本体（`@impeccable/cli-linux-x64` 0.1.21）が公式のチェックサム一覧と一致することを確かめてから、
`detect`（LLM・APIキーを使わない決まった規則での検査）を使いました。スキル（`/impeccable critique` など）は導入していません。

- 先に、わざと問題を入れたページで、描画後の検査が働くこと（5件すべて検出）を確認しました。
- 状態を入れて描画したホームを保存し、スマホ・iPad縦・iPad横の幅で検査しました。

| 対象 | 結果 |
|---|---|
| 変更前のホーム（初回の状態） | 指摘なし |
| CSS 全体（静的検査） | 6件。すべてホーム以外（解説・構造の段階解説の片側だけ太い線など）で、今回は変更していない |
| 標準のホーム（3幅） | 指摘なし |
| 試作のホーム（3幅） | 初回は「クリーム色の背景」が1件 → 通常の背景に戻して0件。「ぼかしのない固い影」の注意1件は意図した表現として残した |

検出ツールの「指摘なし」は、デザインの良さの保証ではありません（決まった規則に当たらなかったという意味）。

Hallmark は今回使っていません（新しいページを作るためのスキルで、既存画面の評価には Impeccable の検出が合うため）。

## 評価（重要度順）と改善
| # | 問題点 | 改善 |
|---|---|---|
| 1 | **単元のどこにいるかが見えない**。「次にやること」は分かるが、診断 → 解説と類題 → 復習 の流れのどこかはホームに無い（単元画面にだけある） | 課題の上に単元名と3段階の流れ（済み・いまここ・まだ）を表示。記録された事実（診断・類題・復習の完了）だけから作る |
| 2 | **同じ枠のカードが3枚並び、強弱が出ない** | カードは「次にやること」の1枚だけに。今日の学習・確認状況は罫線の見出しで区切る |
| 3 | **同じ情報が重なる**。復習がある日、「今日の復習」が課題と記録欄の2か所に出て、「次の復習：今日」も重なる | 記録欄の復習は「復習の予定」1行に統合（今日◯件／今日の分は完了・次は◯日／診断のあとに決まります） |
| 4 | **目標の輪が場所を取る**。数字の割に面積が大きく、スマホで確認状況を下に押し出す | 大きな数字＋細い棒に変更 |
| 5 | **続けている実感が無い** | 今週（月〜日）の「回答した日」を表示。回答の記録がある日だけ印をつけ、「学習済み」「正解」とは書かない |
| 6 | 見出しの文字組みが平板 | 見出しに約物の詰め（palt）、数字は英字書体、見出しは罫線＋太字で区切る。項目に番号 |
| 7 | 小さいスマホ（iPhone SE）で主ボタンが最初の画面の外 | スマホ幅で余白・見出しを詰め、主ボタンが最初の画面に入るように |
| 8 | 「目標を変更」の押せる範囲が小さい（32px） | ホームでは44px |

## 表示する数値の出どころ（新しい数値は作っていない）
- 次にやること・所要の目安：`planner.homeTask`（変更なし）。目安の時間は、もともと書かれている診断（6問・目安10分）だけ
- 単元の流れ：`planner.unitState` の診断・類題の完了／見送り、復習の学習回があるか
- 今日の学習時間：回答ごとの `activeMs`（1問あたり上限あり）の合計（変更なし）
- 今週回答した日：回答の `answeredAt`（アプリ内の日付）
- 復習の予定：`planner.dueReviews` `planner.nextReviewDate`（変更なし）
- 確認状況：`mastery.analyze`（変更なし）

## 変えていないもの
- 採点・出題・確認状況・復習間隔・保存・日付の更新（`js/planner.js` `mastery.js` `scheduler.js` `session.js` `storage.js` など）
- 保存済みの記録の形式・保存場所（`ea-study-v1`）
- ボタンの動作（`data-act="task-…"`、項目を押すと詳しい予定へ、`data-go="settings"` `data-go="history"`）
- ホーム以外の画面（共通の色・文字の設定も変更なし。設定画面に「ホーム画面の見た目」の欄を1つ追加しただけ）
