## 2. 修正した内容と理由
| 修正 | 理由 |
|---|---|
| 意味の問いの画面では、日本語訳・正答・正誤・解説を出さず、答えたあとに表示 | 訳を見てから選ぶと、英文の理解ではなく訳の言葉合わせになるため |
| 類題・復習の空所補充6問を英文だけで出題（訳は解説で表示）。選択肢の中で文法的に正しいものは1つだけ | 訳を見ていない状態で意味の問いに答えられ、独立した根拠になるため |
| 答える前に日本語訳を見たか（`translationShown`）を記録し、訳・解説・ヒントを見たあとの意味の答えは「参考」として記録 | 見た情報に応じて、その答えから判断できることを変えるため |
| 意味の確認を「訳を見ずに確認できた／参考のみ／再確認が必要／まだ確認していない」に分けた | 理由を聞いていないことや、訳を見たあとの正解を「理解している」と扱わないため |
| 理由を聞く条件を決め（5-4）、聞いた・聞かなかった理由を記録。1回の学習で3問まで | 負担を抑え、判断材料が足りないときに絞って聞くため |
| 空所補充の選択肢に to で始まる誤りを加えた（to playing など）。表示順を毎回入れ替える | 「to のあるものを選ぶ」や位置の暗記で正解できないようにするため |
| 意味の確認問題を3問追加。誤りの選択肢は、ほかの用法との取り違えから作った（inf-p-n6, a6, v6） | 理由を取り違えたときや、訳なしで確かめたいときに使う別の英文が必要なため |
| 選択肢なしの英作文を「〜するために」にも追加（inf-p-v7） | 選ぶだけでなく作れるかも確かめるため |
| 追加の確認問題を初期設定で2問まで（変更可） | 依頼の目安に合わせた |
| 根拠を「同じ問題の解き直し／別の問題・解説直後／別の問題・自力／後日の復習」に分けて表示 | どの種類の根拠かを講師が区別できるようにするため |
| 旧版の空所補充（正答だけが to で始まる版）の回答を判定から除外し、版を3にした | 形の手がかりで選べた回答を理解の根拠にしないため。履歴には残る |
| 保存形式を v3 にし、v2 の記録に「訳を見ていたか」を補う（控えを残す） | 既存の記録を消さずに新しい判定へ引き継ぐため |

## 3. 一人の生徒の学習例
`node tools/scenario.mjs` で、実際の判定ロジックのまま再現した結果が `docs/learning-examples.txt` にあります。要点は次のとおりです。

**生徒A：診断で「〜すること」を間違え、類題で意味の問いを取り違える**
1. 1日目
   1. 診断の inf-d1 で ×。解説を読み、同じ問題を解き直して ○（「解き直し」として記録）。
   2. 類題 inf-p-n1（英文だけ）で答えは ○。意味の問いは ×（解説を見たあとなので「参考」）。
   3. 訳なしの意味の確認問題 inf-p-n2 が追加され、○。ただし「解説直後の確認」として記録。
   4. 結果：「最近の誤答あり・再確認が必要」。意味の確認は「再確認が必要」。次回は1日後。
2. 2日目の復習：1問目は英文だけの inf-p-n4。答え ○、意味の問いも ○（訳なし）。
   → 誤答と意味の再確認が解消し、「別の問題でも自力正解」。次回は3日後。
   2問目の並び替え（日本語つき）では、意味の問いを聞かない（訳を見ているため）。
3. 5日目の復習：英文だけの意味の確認問題などに正解。→「後日の復習でも正解」。次回は7日後。

**生徒B：診断・類題はすべて正解。5日目の復習で「〜するために」を自信なしで正解**
1. 1日目：類題（英文だけ）で意味の問いにも訳なしで正解。→ 3項目とも「別の問題でも自力正解」。次回は3日後。
2. 5日目：「〜するために」の意味の確認問題に正解したが、「自信がない」を押した。
   → 実績は上がらず「自力で正解・本人は自信なし」。間隔は延ばさず、3日後に再確認。
3. 8日目：「〜するために」の別の問題に、自信がないの申告なしで正解。意味の問いを聞き（前回の自信なしが残っていたため）、○。
   → 解消し、「後日の復習でも正解」。次回は7日後。

## 5. まだ確認できていないこと
- 実機の iPad（Safari）での操作
- 追加・変更した英文と選択肢の自然さを、辞書・文法書で照合すること
  - 一般的な中学英語の範囲で作っています。
  - 「to ＋ -ing」の誤りの選択肢は「この文では to のあとに動詞の原形」と説明し、すべての場合に誤りとは書いていません。
- 意味の問いの3つの選択肢（「〜すること」「〜するための」「〜するために」の役割）は、どの項目でも同じです。
  - 選択肢の文そのものを覚えて答えることはできます。ただし、どれが正しいかは英文によって変わるので、文の意味を読まないと正解できません。
  - 選択肢の言い回しを英文ごとに変えるかどうかは、試用後の検討事項です。
- 生徒が実際に使ったときの負担（意味の問いの頻度・上限3問が適切か）
