## Impeccable について
この環境には Impeccable（デザイン用のスキル／検出ツール）は導入されておらず、使えませんでした。
npm パッケージ（impeccable 4.8.2）は見えますが、外部コードの実行はこのセッションでは許可されていません。
使う場合は、手元の端末でリポジトリのフォルダから次を実行します。

```
npx impeccable install -y --providers=claude --scope=project   # スキルを .claude/ に入れる
# Claude Code の中で
/impeccable init
# 検出だけ使う場合（ファイルは変更しない）
npx impeccable detect index.html css/
```

## 評価（重要度順）と改善
| # | 問題点 | 改善 |
|---|---|---|
| 1 | **数値カード3枚が同じ強さで並び、優先順位が見えない**。「今日の復習 1件」は上の課題と重複、「再確認が必要な項目」は下の一覧と重複。スマホでは3枚が縦に積まれ、確認状況が2画面目に押し出される | 3枚のカードを廃止。時間・目標・復習を「今日の学習」1枚にまとめ、再確認の数は一覧の見出しに移した |
| 2 | **学習時間と目標が分かりにくい**。0分のとき細い灰色の線だけで、「あと何分か」が書かれていない | 目標に対する輪＋「目標まで あと◯分」。達成時は「目標を達成しました」。その場から目標を変更できる |
| 3 | **復習予定が矛盾して見える**。今日が予定日でも「次の復習予定：11月8日（日）」と日付だけ出る | 予定日が今日なら「今日」、先なら日付＋「2日後」。今日の復習は「1件 残り」「完了」「なし」で表示 |
| 4 | **課題完了時にボタンが1つもない**（行き止まり） | 「解説と回答を見返す」を控えめなボタンで表示 |
| 5 | **iPad 横で課題カードが横長すぎ**、文が1行に長く伸び、右側が空く | 幅900px以上で「次にやること」と「今日の学習」を左右に配置。全体幅も少し狭めた |
| 6 | 装飾：課題カード上端の太い青帯、本文の大半が太字・大文字で強弱が平板 | 青帯を外し、色は藍色1色＋状態色に限定。「次にやること」が唯一の濃いボタン |
| 7 | アイコンが文字記号（→ ！）のみで、種類ごとの手がかりがない | 線の太さをそろえた小さなアイコン（診断・復習・完了・時計・予定）を課題と数値の見出しにだけ使用 |
| 8 | スマホで主ボタンが内容幅のまま | スマホでは主ボタンを全幅にして押しやすく |
| 9 | 確認状況の注意書きが見出し横に長く出て、一覧より先に読まされる | 凡例（■□□）付きで一覧の下に移動 |

背景画像・挿絵はもともと無く、今回も追加していません。
